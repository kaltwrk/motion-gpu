# Spektral brand artwork

These assets preserve the project's own logo. They are not Nucleo interface icons.

| Asset                          | Source                            | Original name                  |
| ------------------------------ | --------------------------------- | ------------------------------ |
| `logo.svg`                     | Spektral project branding         | `spektral-logo.svg`            |
| `apple-touch-icon.png`         | Existing Spektral app icon        | `apple-touch-icon.png`         |
| `web-app-manifest-192x192.png` | Existing Spektral app icon        | `web-app-manifest-192x192.png` |
| `web-app-manifest-512x512.png` | Existing Spektral app icon        | `web-app-manifest-512x512.png` |
| `../../../../../../icon.png`   | Existing Spektral repository icon | `icon.png`                     |

The binary PNG files cannot contain source-code comments. Their provenance
is recorded here; the original export history of those binary files is not recorded
in the repository. SVG files also carry an inline source comment.

The `/favicon.svg` endpoint renders `logo.svg` directly.
