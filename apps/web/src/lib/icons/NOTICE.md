## UI Outline 18 sources

All 36 interface icons were copied from the published npm package
[`nucleo-ui-outline-18@1.5.1`](https://www.npmjs.com/package/nucleo-ui-outline-18/v/1.5.1).
The audited source is the npm tarball, not a local SVG export or the Essential set:

- Tarball: https://registry.npmjs.org/nucleo-ui-outline-18/-/nucleo-ui-outline-18-1.5.1.tgz
- Integrity: `sha512-YKEjmGkZg701eKXOcTi3CDkOadIZaGxQfNYQ5YDfFdow7hd24L3FqRhXtYenImLY4Iekdc4D+Qiw8hV93peYXw==`
- Source files: `dist/components/<original name>.js`

Each Svelte component preserves the package's geometry, element order, and SVG
attributes, including `data-color`, `data-stroke`, opacity, and transforms. React
attribute names are converted to SVG attribute names. `IconRoot` supplies the
18 × 18 viewBox; strokes use `currentColor` and a configurable `strokeWidth`
(default 1.5). The React package is not a runtime dependency.

## Audit changes

- Preserved the filled 16 px `BoltIcon`: it identifies Bolt.new in the
  documentation actions menu and is a brand logo, not a generic lightning glyph.
- Restored the exact npm link and magnifier paths and missing SVG attributes.
- Restored `IconSquareTerminalOutline18` without the local horizontal reflection.
- Verified that the existing copy artwork is `IconTasks2Outline18`, the theme
  artwork is `IconDarkLightOutline18`, and the table-of-contents artwork is
  `IconTableRowsOutline18`.
- Kept all brand geometry unchanged and added source comments to every icon.
- Found no Lucide imports or dependencies. Remaining Lucide strings are the
  prohibition in repository instructions, ESLint configuration, and lint tests.

The sidebar trigger uses `SidebarLeftIcon` and `SidebarLeftClosedIcon` with the
shared tooltip and icon transition components. The persistent desktop TOC has no
visibility toggle; its obsolete right-sidebar icons were removed.
